# Handmade by Kennedy

Portfolio of sewing, crochet, and knitting projects.

## Adding a project
1. Put the photo(s) in the `images` folder (JPG, ideally under 1600px wide).
2. Open `projects.js` and copy one of the lines. Change the title, category, and photo names.
3. Push to GitHub. The site updates in about a minute.

## Custom domain later
Add a file named `CNAME` containing just your domain (e.g. `handmadebykennedy.com`),
then point the domain's DNS at GitHub Pages and set the domain under Settings > Pages.
